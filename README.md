This is a prototype / first version of my Quaver Map Pack Maker (version 0.1)

I will be improving this over time to be more efficient, have more QOL features and guard against more errors.
For now though, if you follow the instructions in the app it works.


Special thanks to A6sT for helping figure out the process of creating a new difficulty.








INSTRUCTIONS
Create a folder and drop the .exe into there

Drop ONE image file (png, jpg, jpeg) into the center for a background.

Drop ONE image file (png, jpg, jpeg) into the center for a background.

Set your pack's name and the creator of the pack then press confirm.

Drag your QP files (you can drop them all at once) and press export.

in the folder where you dropped the .exe, you will find an OUTPUT folder containing your map pack.
